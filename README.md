# BioHack Medizone 2026

AI-assisted genomic sequence analysis and interpretation platform.

## Overview

Our platform aims to make genomic sequence analysis easier to understand for users without extensive bioinformatics experience.

### Core Workflow

DNA Sequence
→ Analysis
→ Visualization
→ AI Explanation

## Project Structure

- `frontend/` — Web interface and data visualization
- `backend/` — Sequence analysis and API
- `docs/` — Project documentation
